Case study 01

Two BI tools, built with the team first

I ran two digital projects for the marketing team. The first was a set of Power BI dashboards to track organic and paid traffic across Google Ads and Meta Ads. The second came from the director, because he wanted to digitalise Meta ads spend auditing. I advised him on using an AI agent, Power BI and Tableau for it. Both projects followed the same delivery lifecycle, so the people using the tools shaped them before anything was built.

  1. Requirements

    Chaired meetings with the marketing team to understand their priorities. Then ran impact analysis to identify the key requirements.

  2. Prototype

    Built a prototype to show how the BI tools would work, before any technical development.

  3. UAT

    Designed a user acceptance testing framework ahead of the build, so the team could check the tool against their needs.

  4. Delivery

    Delivered the dashboards and the auditing tool, which visualised underperforming ads.

−20%ad spend after the BI dashboard was delivered
+15%conversion once underperforming ads were visible

Case study 02

Digitalising the pricing model

My manager wanted to digitalise the pricing model, so I advised on it using Excel and AI tools. First, I built a cost reporting dashboard that recorded and analysed the KPIs behind each price. Then I built a dynamic pricing and cost estimating mechanism on top of it, which made pricing much faster.

KPIs tracked in the dashboard

  • Competitor price
  • Price difference vs competitors
  • Marginal cost and profit
  • Risk premium
  • CPI
  • Inflation rate
  • Overhead cost
  • Target profit margin
